# Paper scaling panels

The four PDFs here are the exact dense, sparse, local and RHG scaling panels
included in the paper. Their source CSVs are in the parent folder.

All four panels were regenerated from those CSVs and matched the paper images
pixel for pixel at 72 dpi. A new PDF can have a different timestamp without
any visible difference.

Use the [verified plotting commands](../../../REPRODUCING.md#scaling-panels-from-saved-circuit-results).
The paper uses a legend size of 24, two legend columns (three for local), and
both exponential and power-law fitted extensions. These extensions are fits,
not extra compiled circuits. Different default styling can change the layout.

Plots drawn from freshly compiled CSVs can have different points and error
bars. The [parent README](../README.md) explains the seed sequence and the
placement timeout responsible for observed rerun variability.
