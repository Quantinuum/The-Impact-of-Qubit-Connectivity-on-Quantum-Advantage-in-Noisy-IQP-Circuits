# Reproduced outputs

[Browse the generated figures](reference/README.md) before running the code.
The release includes 23 regenerated PDFs and PNG previews: four scaling panels,
five phase panels (including RHG-127), four percolation panels and ten topology
panels. The separately drawn circuit schematic remains in
[paper_images/](../paper_images/README.md).

The `reference/` folder is included in Git. Commands in
[REPRODUCING.md](../REPRODUCING.md) write your own outputs to the other folders
here, which Git ignores. This keeps the included examples available for comparison.
